# Current documentation

This directory describes the supported Structured A3 workflow and its
operational contracts. Historical experiments, audits, and superseded model
specifications are preserved separately under [`../history/`](../history/).

The [current status page](status.md) is the single source for model vintages,
artifact roots, and qualification state. The [model-development decision
register](model_development_decisions.md) records completed A3–A6 and
point-proximity findings.

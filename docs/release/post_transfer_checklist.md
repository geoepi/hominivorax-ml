# Post-transfer checklist

- [ ] Transfer the private repository to `geoepi`.
- [ ] Verify the target name is `geoepi/hominivorax-ml`.
- [ ] Verify organization permissions and the `main` default branch.
- [ ] Configure branch protection: require pull requests and passing CI,
  prevent force pushes, and prevent branch deletion.
- [ ] Confirm CI runs under organization ownership.
- [ ] Update the canonical repository URL where necessary.
- [ ] Update local and Atlas remotes.
- [ ] Verify the immutable research tag survived transfer.
- [ ] Verify issue templates and configure Discussions if desired.
- [ ] Confirm the license decision and citation metadata.
- [ ] Run the history/security audit one final time.
- [ ] Make the repository public only after all blockers are cleared.
- [ ] Test a clone from the public URL.
- [ ] Run the public-facing documentation link check.

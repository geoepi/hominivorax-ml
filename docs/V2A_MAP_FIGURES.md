# V2-A Map Figures

Task 3E produces continuous cell-level maps with `ggplot2` and exact modeled
grid cells rendered with `geom_raster()`. The maps are generated by
`scripts/task3e_raster_outputs.R` from the GeoTIFF outputs; they are not node
scatter plots and do not resample the modeled grid.

## Figure 1: current estimates

`figures/v2a_figure1_current_estimates.png` and `.pdf` show:

- top row: predicted probability for 2026-W17, W23, and W29;
- bottom row: predicted expected detection count for the same weeks.

Probability panels use one fixed viridis-like scale from 0 to the maximum
probability across 2026-W17 through W29. Expected-count panels use one fixed
raw-value scale across the same range. No square-root or log transformation is
used. Country boundaries, state/province boundaries, and coastlines/land
outlines are thin, subdued overlays from the existing Natural Earth boundary
files already available in the project environment.

## Figure 2: pseudo-nowcast reconstruction

`figures/v2a_figure2_pseudo_nowcast_2026-W23.png` and `.pdf` contain:

1. 2026-W23 pre-outcome pseudo-nowcast probability;
2. 2026-W23 pre-outcome pseudo-nowcast expected count;
3. scored probability with the label “observed detections overlaid after
   scoring”.

The raster in the third panel remains prediction-only. Observed detections are
hollow red circles supplied by a separate overlay table. The W26 prediction-
only pseudo-nowcast rasters are also written for later customization.

## Output quality

PNG files are rendered at 300 dpi-equivalent resolution and PDF files are
written as vector-capable publication outputs. The output manifest records the
exact scale policy, focal weeks, paths, CRS, nodata value, and checksums.

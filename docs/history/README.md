# Development history

These documents preserve the scientific and computational development history
of the project. They are not required to run the current Structured A3
workflow and may describe superseded model architectures, predictor sets,
domains, or evaluation stages.

The history includes the original STGNN/GConvGRU work, domain revisions,
structured-model comparisons, predictor audits, neural-model evaluation, and
historical holdout reports. Current operational guidance belongs under
[`../current/`](../current/).

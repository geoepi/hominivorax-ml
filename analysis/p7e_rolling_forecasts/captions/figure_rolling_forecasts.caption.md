# Figure P7E-1. Rolling-origin focal-region nowcasts

Panel A shows observed positive cells (black) and expected positive-cell burden (colored target-week points) for all 21 rolling origins from 2026-W16 through 2026-W36 and horizons h=1, h=2, and h=3. Forecast points are connected within issue week; the orange-highlighted threads are the deterministic subset W16, W20, W24, W28, W32, and W36. Panels B and C show signed forecast error and its distribution by horizon, respectively; error is expected minus observed positive cells. The focal region is the fixed EPSG:4326 box [-107.5, -96.0] longitude × [24.0, 33.0] latitude containing 1,689 canonical cells. Values are bounded descriptive aggregations from the canonical P2 rolling-origin archive. This display is not a regional uncertainty interval and does not imply that future environmental conditions were observed at issue time.

# Candidate Figure P7E-2. Rolling-origin expected-count burden

The candidate count display uses the same origins, horizons, focal cells, and target-week alignment as Figure P7E-1, replacing positive-cell burden with observed total count and full hurdle expected count. Panels B and C use expected minus observed total count. This is a technical candidate display; no count recalibration or regional uncertainty band is applied.

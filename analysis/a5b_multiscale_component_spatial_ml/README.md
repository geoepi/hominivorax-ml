# A5B Multiscale Component-Specific Spatial ML

This directory contains the prespecified A5B follow-up to the completed A5
bounded comparison. It is a `DEVELOPMENT_INFORMED_FOLLOWUP`, not independent
validation or a production model.

Large runtime products are routed to `TEMPORARY_90DAY_STORAGE` under
`/90daydata/disease_ecology/`. Compact metrics, provenance, reports, and
figure-source status are promoted to the durable project worktree. The
temporary filesystem is automatically deleted after 90 days without activity.

The A5B architecture is deliberately narrow: four response-independent exact
graph-distance shell operators, hidden width 8, a centered occurrence residual
head, and no positional encodings or learned adjacency. The hybrid uses only
the immutable frozen A4-S count arrays when they can be extracted exactly.

# P5A Prespecification — Issue-Time Environmental Proxy Validation

## Purpose and scientific boundary

P5A evaluates whether the frozen `STRUCTURED_A3` model can receive a
prospective issue-time environmental state for the 12 predictors classified
`RETROSPECTIVE_ONLY` in P5. The fitted coefficients, predictor identities,
units, transformations, response, penalty, theta, hurdle structure, support
thresholds, training data, and P0 artifact remain unchanged. The P2
realized-environment rolling-origin predictions remain the reference condition.

This is a conditional environmental-input sensitivity analysis. Non-
environmental predictor values and P2 evaluation records are retained exactly
for paired comparison. The existing P5 limitation for future detection-history
values at h=2 and h=3 is tracked and is not silently resolved by P5A.

## Frozen predictor audit

The 12 environmental predictors eligible for proxy substitution are exactly:

`era5_mintemp`, `era5_soilmoist`, `era5_lai_low`, `agera5_relhum_min`,
`era5land_tmean`, `era5land_soiltemp_l1_mean`,
`era5land_soiltemp_l2_mean`, `era5land_soilwater_l1_mean`,
`era5land_soilwater_l2_mean`, `era5land_surface_pressure_mean`,
`era5land_lai_high_mean`, and `era5land_lai_low_mean`.

Proxying is applied to the frozen feature values, including the already-lagged
ERA5-Land soil-temperature and soil-water features. Those features are not
re-lagged, re-transformed, or redefined. The remaining 22 predictors—static
livestock and imputation terms, calendar terms, detection-history terms, and
the four A3 static additions—are unchanged.

## Issue-time availability rule

For an origin week `T`, issue time is Monday 00:00 UTC immediately after the
completed ISO week `T`. Because P5 found no authoritative product release or
revision-lag metadata, P5A uses a conservative feature-observation cutoff:

`L(T) = T - 1 ISO week`.

Only environmental observations with observation week `<= L(T)` may enter a
proxy. A production implementation must additionally verify that the selected
source vintage has a source timestamp `<= issue_timestamp`; the historical
evaluation does not infer per-week publication timestamps from a retrospective
raster. Any missing, future-vintage, or nonfinite environmental input fails
the origin/proxy rather than silently falling back.

## Proxy contracts

The following candidates are fixed before inspecting results:

### REALIZED_ENV

The unchanged P2 reference condition using the realized target-week
environmental values from the validated P2 feature archive.

### E0_LAST_AVAILABLE

For every eligible environmental predictor and every node,

`X[T+h] = X[L(T)]`, for h=1,2,3.

The value at `T-1` is held constant across all three horizons. This is a
feature-level persistence rule; it does not imply that the future target-week
environment was observed at issue time.

### E1_TRAILING3_MEAN

For every eligible environmental predictor and node,

`X[T+h] = mean(X[T-1], X[T-2], X[T-3])`, for h=1,2,3.

Exactly three valid historical observations are required. The window is never
silently shortened.

### E2_SEASONAL_EXPECTATION

For each target week and node, calculate the mean of environmental observations
with the same ISO week number and observation week `<= T-1`. At least two prior
seasonal cycles are required for every target week/predictor/node combination.
No target-year future observation, outcome, or performance-driven fallback is
allowed. If the archive does not contain two prior cycles, E2 is
`NOT_EVALUABLE`.

## Rolling-origin evaluation

The P2 origins `2026-W16` through `2026-W36` are reused, with h=1,2,3 and
expanding training windows already represented by the stored P2 fit artifacts.
No model is refit. Each origin uses its stored A3 coefficient and
origin-specific training standardization state. E0 and E1 predictions are
generated by presenting the exact 34-column frozen schema to the unchanged
inference function. REALIZED_ENV is read from the immutable P2 archive and is
not regenerated as a competing reference.

Each origin writes an atomic prediction file and terminal ledger entry. The
aggregate is deterministic and can be restarted from completed origins.

## Metrics

For each contract and h=1,2,3, report N, positives, prevalence, Brier,
calibration intercept and slope, log loss, AUROC, and AUPRC. Count metrics are
reported for conditional positive counts and full hurdle expected counts:
MAE, RMSE, signed bias, and observed/predicted totals.

Proxy-minus-realized paired differences are calculated on identical keys.
Dependence-aware target-week block bootstrap intervals use 199 replicates and
seed `20261029`; all spatial rows for a sampled target week remain together.
The bootstrap is used for key differences in Brier, AUPRC, count MAE, and
frontier Brier, not for proxy selection tuning.

Environmental diagnostic errors report mean error, MAE, RMSE, correlation,
and horizon dependence for every eligible predictor and proxy, with family
summaries for temperature, moisture/water, vegetation, and humidity/pressure.

## Frontier and support analyses

Frontier strata use the leakage-safe P2 labels without pooling: previously
occupied, previously unoccupied, and descriptive newly detected frontier
positives. P4 support classes and thresholds are unchanged. Support classes
are recalculated for each proxy from the proxy predictor matrix against the
P4 training-only reference distribution. Support proportions and transitions
from realized to proxy classes are reported. Novelty and absolute prediction
spread are summarized by horizon, support class, and frontier status.

## Proxy selection rule

Candidates are considered in simplicity order: E0, then E1, then E2. E2
cannot be selected if it is infeasible. A candidate is
`OPERATIONALLY_ACCEPTABLE` only if it has at least 99% paired coverage, remains
available at all three horizons, and at every horizon satisfies all strict
negligible-degradation bounds:

* Brier increase <= 0.002;
* AUPRC decrease <= 5% of REALIZED_ENV AUPRC;
* absolute calibration-intercept change <= 0.05;
* full-count MAE increase <= 0.02;
* conditional-count MAE increase <= 0.10;
* frontier Brier increase <= 0.002 where the stratum is estimable; and
* EXTRAPOLATIVE support proportion increase <= 0.05.

A candidate is `ACCEPTABLE_WITH_LIMITATIONS` if it has complete coverage,
stable h=1..3 behavior, and remains within broader bounded limits of Brier
increase <= 0.005, AUPRC decrease <= 10%, absolute calibration-intercept
change <= 0.10, full-count MAE increase <= 0.05, conditional-count MAE
increase <= 0.25, frontier Brier increase <= 0.005 where estimable, and
EXTRAPOLATIVE support increase <= 0.10. Otherwise it is `NOT_ACCEPTABLE`.

The first simple candidate satisfying the strict rule is selected. If none
does, the first candidate satisfying the bounded rule is selected with
limitations. E2 infeasibility is reported as `NOT_EVALUABLE`. No thresholds,
windows, or definitions may change after results are inspected.

## Availability reclassification and decision rules

If a proxy is selected, the environmental availability classification may move
from `RETROSPECTIVE_ONLY` to `PROSPECTIVE_READY_WITH_PROXY_LIMITATIONS`.
`PROSPECTIVE_READY` is not claimed merely because proxy values can be computed;
the source-vintage and P5 non-environmental limitations remain explicit.

P5A ends with `P5A_ENVIRONMENTAL_PROXY_SUPPORTED` when a strict candidate is
accepted, `P5A_ENVIRONMENTAL_PROXY_SUPPORTED_WITH_LIMITATIONS` when only the
bounded rule is met, and `P5A_ENVIRONMENTAL_PROXY_NOT_SUPPORTED` when no
legitimate issue-time candidate is acceptable.

No P0 manifest, model coefficient, P4 threshold, or P5 realized archive is
modified.

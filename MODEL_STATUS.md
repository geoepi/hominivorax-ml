# Model status

Current supported model: **Structured A3**

Model class: penalized spatiotemporal hurdle regression; statistical machine
learning.

Development status: **Frozen**

Historical holdout: **Supported**

Independent prospective validation: **Pending**

Production full fit: **Available on Atlas**

Current supported outputs:

- weekly occurrence probability;
- conditional positive-count mean;
- unconditional expected recorded count;
- GeoTIFF products;
- nowcast PDFs;
- interpretation figures;
- animations.

Unsupported current pathways: GConvGRU, neural, and GNN models. Those model
classes remain in the historical development record only.

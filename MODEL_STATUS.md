# Model status

The supported architecture is the frozen `STRUCTURED_A3` spatiotemporal
hurdle model. The original scientific freeze uses a W16 training cutoff. The
W29 full-fit remains the active production artifact according to the latest
isolation record; the newer W44 full-fit is an unqualified candidate.

See [the canonical current status](docs/current/status.md) for artifact roots,
model identifiers, and qualification states. W44 Q1 retrospective results are
descriptive only because target maturity is uncertified. Independent
prospective qualification of the fixed W44 candidate remains pending.

Neural/GNN, A4, A5, A5B, and evaluated A6 alternatives are not supported as the
production architecture. Their decisions and evidence are in the
[model-development decision register](docs/current/model_development_decisions.md).
